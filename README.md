# REDLINE — Sito Cloudflare Pages

Carica **il contenuto di questa cartella** alla radice di un repository GitHub privato, collega il repository a Cloudflare Pages e usa un sito statico senza build (output `.`).

In seguito modifica SOLO `config.js` aggiungendo i cinque valori WEB Firebase e l'indirizzo del tuo Worker. Non inserirvi credenziali private B2 o password.

La guida completa è nel pacchetto generale, `docs/GUIDA_INSTALLAZIONE_PASSO_PASSO.md`.
